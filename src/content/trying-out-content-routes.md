# Trying Out Content Routes

This post demonstrates the power of Analog.js content routes!

## What are Content Routes?

Content routes allow you to:
- Write content in Markdown
- Use frontmatter for metadata
- Render markdown in Angular components
- Support syntax highlighting

